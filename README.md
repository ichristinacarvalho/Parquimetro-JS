# 🅿️ Simulador de Parquímetro (JavaScript)

> Uma aplicação web interativa que simula o funcionamento de um parquímetro, calculando o tempo de permanência com base no valor inserido e gerenciando o troco.

---

## 🚀 Sobre o Projeto
Este projeto foi desenvolvido com foco na aplicação prática de **JavaScript moderno (ES6+)**, lógica condicional, manipulação de formulários e atualização dinâmica do DOM. A aplicação resolve um problema prático do cotidiano: calcular quanto tempo de estacionamento o usuário tem direito de acordo com as moedas/valores inseridos e retornar o troco correspondente, se houver.

---

## 🛠️ Tecnologias Utilizadas
O projeto foi construído utilizando as seguintes tecnologias:
* **HTML5:** Estruturação semântica da interface do painel do parquímetro.
* **CSS3:** Estilização visual, layout organizado e design responsivo.
* **JavaScript (ES6+):** Lógica de cálculo de tarifas, validação de entrada de dados e manipulação do DOM.
* **Git & GitHub:** Controle de versão e hospedagem do código.

---

## ⚙️ Funcionalidades
* **Inserção de valores:** Permite ao usuário digitar ou selecionar o valor inserido no parquímetro.
* **Cálculo de tempo:** Converte automaticamente o valor monetário no tempo correspondente de estacionamento.
* **Cálculo de troco:** Informa se há valor excedente a ser devolvido ao usuário.
* **Validação de regras:** Evita entradas inválidas ou valores abaixo da tarifa mínima.
